# ごっくんクイズ 〜飲み込みのひみつ〜

▶ **クイズをはじめる:** https://sakusaku117.github.io/gokkun-quiz/

嚥下(えんげ・飲み込み)について楽しく学べる、3択クイズ20問です。子どもから高齢の方まで、スマートフォンで答えられます。

`index.html` をブラウザで開くだけで使えます。インストールや通信は不要です。

## 使い方

- 「スタート」を押すと、問題が1問ずつ出ます。3つの中から答えを選びます。
- 答えるたびに、正解と解説が表示されます。
- 20問が終わると、点数と、まちがえた問題のふりかえりが表示されます。
- スタート画面のボタンで、ふりがなの表示を切り替えられます。

## 問題の分野

| 分野 | 問題数 |
|---|---|
| からだのしくみ | 8問 |
| ごえんと むせ | 5問 |
| 食べかたの くふう | 5問 |
| げんきな ごっくんのために | 2問 |

## プライバシー

名前などの入力欄はありません。回答内容や点数は、どこにも送信・保存されません。アクセス解析や外部サービスの読み込みもありません。

## ご注意

このクイズは一般の方向けの啓発を目的としたもので、病気の診断をするものではありません。飲み込みについて気になることがあるときは、医師や言語聴覚士にご相談ください。
